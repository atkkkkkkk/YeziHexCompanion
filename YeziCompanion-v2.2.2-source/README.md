# 椰子海斗助手 · YeziCompanion

Windows 桌面助手 · [下载成品](https://github.com/atkkkkkkk/YeziCompanion/releases/latest)

独立改名发布，版本 2.2.2。为兼容旧版，沿用原设置目录及单实例标识；请勿同时运行旧版。

国服英雄联盟海克斯大乱斗桌面助手。英雄排名、梯队、胜率和头像来自 [ARAMKit](https://aramkit.com/zh-CN)。

## 启动

退出正在运行的旧版，然后双击「YeziCompanion.exe」。2.2.2 成品自带 Windows x64 运行所需组件，不需要单独安装 .NET。请保留成品目录中的说明及许可文件。

旧版与新版共享单实例保护。旧版还在运行时，启动新版会唤醒旧窗口，避免两个程序同时请求交换。

## 日常使用

- 首次启动默认开启自动抢选、自动接受对局和进游戏打开数据；之后记住你选择的开关状态。
- 点击「设为候选」立即布防；点击空闲英雄立即尝试交换；点击队友持有英雄可等待其被换下。
- 重复点击同一候选会重新尝试，点击「取消候选」才会取消。每次目标出现最多自动尝试 8 次。
- 「共享席空闲」与「队友持有」分开显示。异常快照出现同一英雄重复归属时，优先显示持有状态。
- 当前所选英雄卡片提供详情入口；进入游戏后保留最终英雄信息。
- 当前运行会话内，同一局成功打开网站后不再重复打开。程序在游戏中启动时，从本机官方对局数据识别当前英雄；数据不可用时不会猜测。
- Ctrl+F 定位搜索，Esc 或「清空」清除搜索；点击表头可排序。
- 不需要通过刷新数据来重新布防或重新连接客户端。

## 2.2.2 连接修复

修复客户端日志目录信息显示 0 字节时被错误跳过的问题。本机重启诊断确认：目录显示空文件时，通过共享只读方式打开仍能读到本次启动的连接信息。现在不依赖目录大小，直接限量读取日志；保留认证验证、超时和自动重试。真正空白、尚未写完或不可读的日志仍等待后续重试。本补丁不改变界面布局及抢选策略。

## 2.2 连接与界面更新

- 深黑内容区、固定侧栏、较大的标题与底部当前英雄栏，参考 TIDAL 网页播放器的布局；圆角、控件与留白采用克制的桌面风格。
- 删除客户端发现流程中的 MainModule 读取，避免受保护进程的模块读取阻塞启动。
- 对候选连接限时并行验证，每个地址最多等待 800 毫秒；成功连接的信息仅在当前进程内复用。
- 游戏中新增官方 Live Client Data 只读连接，可在中途启动时识别自己的英雄并打开对应数据。
- 对局数据已连接不等于选人客户端已连接。只读连接不提供抢选与接受对局功能；返回大厅后继续重试客户端。
- 侧栏新增「重新连接」和「指定游戏目录」。指定目录能改善非默认安装路径发现，不能凭空生成客户端连接凭据。
- 当前客户端日志和 lockfile 为空、连接参数不可读时，明确显示「客户端连接暂不可用」，不会一直停留在初始连接提示。
- 官方对局接口仅在游戏进程运行时存在。游戏尚未启动、已经结束或数据接口关闭时，不显示已连接。

参考与接口说明：
[TIDAL 网页播放器](https://listen.tidal.com/)
[Riot 官方 Game Client API](https://developer.riotgames.com/docs/lol#game-client-api)

Mobbin 指定参考页未能直接读取，视觉设计结合 TIDAL 公开界面参考完成。

## 保留的稳定性改进

- 重新统一灰绿色界面、字体层级、按钮状态、表格居中与小窗口列宽。
- 修复 WebP 英雄头像显示：后台限并发解码并缓存，下载失败显示名称占位。
- 修复请求超时导致监控循环退出；超时后重新连接并清除过期共享席显示。
- 刷新保留现有英雄行、候选及筛选，不因重建行而丢失按钮状态。
- 切换、取消或重新布防后，旧请求结果不覆盖新候选。
- 事件接收不等待交换请求返回，持续接收后续共享席状态。
- 运行期间每两小时检查英雄数据更新，手动刷新期间阻止重复刷新。
- 更新失败保留有效缓存，并在底栏标明「离线缓存」。缓存和设置使用临时文件后替换，避免写到一半损坏。
- 请求日志队列设置容量上限，避免磁盘异常导致内存无限增长。
- 打开浏览器失败不会使程序崩溃；数据尚未加载时，不提前消耗本局网站打开机会。

## 数据与诊断

设置、数据缓存、头像缓存、连接状态和请求诊断保存在：

`%LOCALAPPDATA%\HexARAMCompanion.V2`

底栏展示数据版本及获取时间。网站尚未更新时，本软件不会自行生成新版本的胜率。英雄联盟客户端接口或 ARAMKit 页面结构改变时，仍可能需要软件适配。

程序使用客户端本地接口，不注入游戏、不修改游戏文件、不读写游戏内存、不模拟鼠标键盘。程序并非 Riot Games 或腾讯的官方产品。

## 验收与边界

2.2.2 增加 5 项日志读取检查，共 37 项离线检查：目录大小缓存为 0 但打开文件可读、真正空文件、未写完日志后续恢复、无效端口、取消读取；保留游戏中途启动、只读连接降级、候选操作、延迟响应、刷新、JSON、缓存及布局检查。测试仅使用本地固定样本及模拟请求，不发送真实交换或接受对局请求。

运行 `YeziCompanion.exe --self-test-ui` 会在成品目录的 `qa` 子目录写入报告。验收模式不显示窗口、不发现客户端、不打开浏览器，也不修改日常设置。Tests 中的排名与头像为固定验收样本，不代表最新数据。

另有纯只读诊断入口：运行 `YeziCompanion.exe --diagnose-connection` 会检查本机客户端与对局接口，并在 `qa/connection-test.json` 写入结果。它不显示窗口、不发送交换或接受请求、不打开浏览器，不记录账号凭据。

这些检查验证软件逻辑与界面，不能替代当前国服客户端下的实战测试，不能保证每次都抢到英雄。服务器响应、其他玩家操作和网络状况仍会影响结果。

